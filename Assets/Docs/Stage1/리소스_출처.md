# 리소스 제작과 출처

- 자개함 `mother_pearl_chest.png`, 목제 목욕통 `wooden_bath_tub.png`, 낮은 탁자 `dorm_low_table.png`는 내장 image_gen으로 새로 생성했습니다. 투명 배경이며 원본 PNG는 이 폴더에 있습니다.
- 침대·옷장·벽·눈 덮인 건물·소나무·등롱·책·물병은 앞서 이 대화에서 제작한 이미지를 재사용했습니다.
- 항아리·그릇·컵은 사용자가 제공한 **PVGames Infernus Free**의 Infernus_Jar.png, Infernus_Bowl.png, Infernus_Cup.png를 사용했습니다.
- 서 있는 동문과 대화창의 인물 그림은 사용자가 제공한 흰 바탕 PNG를 사용했습니다.
- 플레이어, 한글 폰트, 조사 표시 등은 프로젝트의 기존 리소스입니다.

팔레트용 시트는 Unity에서 투명 여백을 정리하고 칸 크기에 맞게 투명 공간을 덧붙여 만들었습니다. 원본 그림의 색과 내용은 바꾸지 않았습니다. Sprite Editor 데이터 공급자로 칸을 자르고 Tile 에셋을 등록했습니다.

생성 프롬프트는 `generation-prompts.json`, 타일별 원본·팔레트 좌표는 `tile-catalog.json`에 있습니다. 별도 이미지 생성 API나 CLI는 사용하지 않았습니다.
