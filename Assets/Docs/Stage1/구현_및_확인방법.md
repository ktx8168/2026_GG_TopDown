# 작은 문파 기숙사와 페인터 사용법

작업 씬: `D:\2025280088\2026_GG_TopDown\Assets\Scenes\Stage1_RoomAndCourtyard.unity`

## 바뀐 배치

- 2층 기숙사는 20×12칸에서 **14×11칸**으로 줄였습니다.
- 왼쪽 3개, 오른쪽 3개, 총 **침대 6개**를 Wall 타일로 칠했습니다.
- 개인 자개함을 침대 옆에 붙이고, 가운데는 계단에서 서신·창문까지 이어지는 통로로 비웠습니다.
- 두 구역을 합쳐 자개함 10개, 목욕통 2개, 옷장·탁자·항아리·그릇·책 등을 배치했습니다. 1층의 왼쪽은 식사·수납 자리, 오른쪽은 세면 공간입니다.
- 동문 3명의 몸 그림은 모두 사용자가 제공한 **흰 바탕 인물 PNG**로 바꿨습니다.
- 일반 배경용 SpriteRenderer 오브젝트 138개를 정리했습니다. 침대·가구·벽·나무·건물은 실제 타일맵에 있습니다.

## 층 구분

| Active Tilemap | 놓는 것 |
| --- | --- |
| Ground | 실내 나무 바닥, 눈 바닥, 눈 덮인 돌길 |
| Wall | 침대, 함, 옷장, 목욕통, 탁자, 벽, 나무, 건물 등 막는 것 |
| Deco | 컵·그릇·책·등롱처럼 겹쳐 놓는 장식. 통과를 막아야 하는 바탕 가구는 Wall에 있음 |

플레이어·NPC·UI와 서신·창문·계단·출입문 등 상호작용 대상의 그림 및 Trigger는 기존 GameObject 구조를 유지했습니다. 가구마다 BoxCollider를 따로 붙이지 않고 Wall의 TilemapCollider2D와 CompositeCollider2D를 사용합니다.

## 침대나 소품을 직접 칠하는 방법

1. **Play를 끕니다.**
2. Unity 메뉴 **Window → 2D → Tile Palette**를 엽니다.
3. 팔레트는 **UrbanPalette**, **Active Tilemap은 Wall**을 선택합니다.
4. 기존 도시 타일 오른쪽에 새 소품들이 있습니다. 침대의 **가로 2칸 × 세로 3칸 전체를 드래그해서 선택**합니다.
5. **Brush(B)**로 Scene에 찍으면 침대 전체가 놓입니다. 지울 때는 Eraser(D)를 사용합니다.
6. Ctrl+S로 씬을 저장합니다.

바닥을 칠할 때는 Active Tilemap을 Ground로, 컵이나 책을 겹쳐 칠할 때는 Deco로 바꿉니다. Tile Palette 자체를 편집하는 모드와 Scene에 칠하는 모드를 구분하세요.

| 새 소품 | 선택할 묶음 크기 | 팔레트 시작 셀 |
| --- | --- | --- |
| 침대 | 2×3 | (22, -3) |
| 옷장 | 1×2 | (27, -2) |
| 목재·회벽 | 2×1 | (31, -1) |
| 낮은 탁자 | 2×2 | (48, -2) |
| 자개함 | 1×1 | (53, -1) |
| 목욕통 | 2×2 | (57, -2) |

새 타일 에셋: `Assets/Tiles/SectDormitoryPainter`.

칸별로 잘라 둔 시트: `Assets/Art/SectDormitory/PainterSheets`.

원래 UrbanPalette의 414칸은 보존했습니다. 새 소품 96칸과 기존 바닥 3칸이 추가되어 총 513칸입니다. 각 조각은 1유닛 정사각형이며 Grid/Tilemap 스케일과 Tile 변환은 1을 유지합니다. 제공된 16px 타일은 그대로 두고, 큰 원본 그림은 해당 그림의 한 칸 픽셀 수에 맞춰 잘랐습니다.

## 기존 진행은 그대로

- 서신 + 2층 동문 1명 + 1층 동문 2명의 증언 = 단서 4개.
- 대사를 마지막까지 읽고 닫아야 단서가 늘며, 재대화로는 중복 획득되지 않습니다.
- 계단은 단서 없이도 사용하며, 문파 출입문은 단서 4개가 있어야 이동합니다.
- 이동은 방향키/WASD, 조사·대화·문 이용은 E, 선택지는 숫자 1/2입니다.
- 새 배치에 맞춰 서신·창문·2층 동문·계단의 조사 위치와 도착 위치를 함께 옮겼습니다.

## 캐릭터 사진 교체

대화창 사진: **Canvas → DialoguePanel → CharacterPortrait → Image → Source Image**.

서 있는 NPC 그림: **Stage1_SectDormitory → NPC_Placeholders → 해당 NPC → TemporaryBody → SpriteRenderer → Sprite**.

새 PNG는 먼저 Texture Type을 Sprite (2D and UI)로 설정하고 Apply합니다. 대화창 Image의 Preserve Aspect는 켜 둡니다. 현재 제공한 흰 바탕 그림은 원본을 수정하지 않았습니다.

## 검증과 참고

작아진 방의 중앙 통로·서신·창문·동문 접근과 네 단서 수집, 계단·눈길 왕복을 실제 게임 키 입력으로 확인했습니다. 침대 충돌과 팔레트에서 침대 묶음을 집어 칠하는 동작도 별도로 점검했습니다.

배치 방식은 게임그래픽실전 6강 4.4~4.10의 Grid/Ground/Wall/Deco, 여러 칸 선택, TilemapCollider/Composite 구성을 참고했습니다. 새 런타임 게임 로직은 추가하지 않았습니다.
